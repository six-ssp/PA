# 2026 高教社杯 A 题：药材的烘干问题

本仓库给出四问的统一机理模型、Python 数值求解代码和按官方模板生成的完整结果文件。最终结果采用 161 个径向节点的守恒型有限体积法与隐式 BDF 时间积分。

官方题面来源：[全国大学生数学建模竞赛官网](https://www.mcm.edu.cn/html_cn/node/27b6e148f8113f09b0269f64a02629fb.html)。

## 一、建模假设

1. 药材是半径远小于长度的均匀圆柱。忽略两端效应，只研究轴向中部截面的径向传热、传质，温度和水分浓度仅依赖半径 `r` 与时间 `t`。
2. 初始温度和干基含水率均匀，分别为 `28 °C` 和 `2.55 kg/kg`。
3. 药材内部无体热源。题目未给出汽化潜热、相变速率等参数，因此不额外引入蒸发潜热项；水分通过经验扩散系数对温度场产生的影响，体现在变物性的 `ρ(C)、cp(C)、k(C)` 中。
4. 表面对烘房采用第三类边界条件，对流换热系数为 `25 W/(m²·K)`，对流传质系数为 `8×10⁻⁷ m/s`。
5. 附件 1 的环境数据在相邻采样时刻之间线性插值；超过 `14400 s` 后保持最后一个实测值。
6. 问题 4 将附件 2 的半径做分段线性插值。无量纲坐标 `x=r/R(t)` 随固体收缩，是材料坐标；收缩通过扩散尺度 `1/R(t)²` 和表面边界进入方程。

## 二、控制方程

圆柱坐标下的径向传热方程为

```text
ρ(C) cp(C) ∂T/∂t = (1/r) ∂/∂r [ r k(C) ∂T/∂r ]
```

水分扩散采用变系数 Fick 第二定律

```text
∂C/∂t = (1/r) ∂/∂r [ r D(C,T) ∂C/∂r ]
```

圆柱中心使用对称边界，药材表面使用对流边界：

```text
∂T/∂r(0,t) = 0,              ∂C/∂r(0,t) = 0
k ∂T/∂r(R,t) = hT [T∞(t)-Ts], D ∂C/∂r(R,t) = hm [C∞(t)-Cs]
```

其中各问的 `ρ、cp、k、D` 完全按题目附录 2-4 给出的经验公式计算。代码中温度场以摄氏度积分，仅在含 Arrhenius 指数 `exp(-3850/T)` 时转换为开尔文。

## 三、数值方法

- 空间：`x=r/R(t)∈[0,1]` 上的节点有限体积法，161 个径向节点；控制体面积积分保留圆柱几何权重。
- 界面系数：相邻节点的算术平均。`D(C,T)` 是连续状态函数，不能用分层介质的调和平均，否则会人为放大低含水表层的阻力。
- 时间：SciPy `solve_ivp(method="BDF")`，最大内部步长 60 s，`rtol=2×10⁻⁶`，`atol=2×10⁻⁸`；利用连续插值按题目要求输出每 1 s 或每 60 s 的结果。
- 停止条件：`max_r C(r,t)=0.15`。由于中心点最后达到阈值，事件时刻即烘干结束时刻。

网格加密结果如下，主要烘干时长已基本收敛：

## 五、仓库结构与运行

```text
src/model.py          控制方程、物性、有限体积离散和 BDF 求解
src/run_all.py        运行四问并生成中间数值结果
export_results.mjs    将数值结果写入官方 Excel 模板
附件1.xlsx            烘房环境实测数据
附件2.xlsx            半径收缩实测数据
附件3/                官方结果模板
results/              已生成的四个完整结果文件
```

运行数值模型：

```powershell
python -m pip install -r requirements.txt
python src/run_all.py
```

导出 Excel（需要 Node.js 和 `@oai/artifact-tool`）：

```powershell
npm install
npm run export
```

所有正式数值均从 `src/run_all.py` 生成，README 表格和 Excel 文件使用同一份模型输出，避免人工抄写产生不一致。
